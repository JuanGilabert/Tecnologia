## Convenciones

- Usar nombres descriptivos en minúsculas.

- Mantener los recursos relacionados cerca de sus apuntes.

6. Configuración del repositorio público
Añadiría desde el principio estos archivos:
- README.md: descripción, índice principal y guía de navegación.
- CONTRIBUTING.md: convenciones para añadir o modificar contenido, aunque seas el único autor.
- LICENSE: licencia que indique qué permisos concedes sobre tu contenido.
- .gitignore: exclusiones para archivos temporales, cachés y artefactos generados.
- docs/convenciones.md: reglas de nomenclatura, estructura y clasificación.
Hay dos aspectos especialmente importantes en un repositorio público:
Licencia. Si los apuntes son tuyos y quieres permitir que otros los reutilicen con atribución, puedes valorar una licencia Creative Commons como CC BY 4.0. Para código, una licencia de software como MIT puede ser más adecuada. No tienes por qué usar la misma licencia para todo, pero debes dejar claras las condiciones y tener derechos para compartir el material de terceros.
Privacidad y propiedad intelectual. No subas credenciales, claves, datos personales, documentación interna de empresas ni presentaciones ajenas que no tengas permiso para redistribuir. Un repositorio público puede ser clonado y sus datos pueden seguir disponibles incluso después de borrar un archivo.

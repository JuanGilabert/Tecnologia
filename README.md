# 💻 Tecnología — Base de conocimiento informática

Repositorio personal de **apuntes, documentación técnica, ejemplos y recursos de informática**. Un espacio organizado para aprender, consultar y consolidar conocimientos sobre las principales áreas de la tecnología.

El objetivo es construir una base de conocimiento estructurada, mantenible y en constante evolución, que facilite tanto el aprendizaje como la consulta rápida de conceptos, herramientas y buenas prácticas.

---

## 📝 Convenciones de documentación

Para mantener el repositorio ordenado y facilitar su mantenimiento, se establecen las siguientes convenciones:

- Utilizar nombres descriptivos y coherentes para archivos y directorios.
- Escribir los nombres de archivos en minúsculas y separar palabras con guiones cuando corresponda.
- Priorizar Markdown (`.md`) para apuntes y documentación textual.
- Mantener juntos los documentos, ejemplos y recursos que pertenezcan al mismo tema.
- Evitar duplicar contenido cuando pueda resolverse mediante enlaces internos.
- Incluir ejemplos prácticos cuando ayuden a comprender un concepto.
- Actualizar la documentación cuando cambien las instrucciones o las tecnologías descritas.
- Utilizar las plantillas disponibles para mantener una estructura homogénea.

## 🚀 Cómo utilizar este repositorio

1. **Explora las categorías** para localizar el área que te interesa.
2. **Consulta los apuntes y recursos** disponibles dentro de cada directorio.
3. **Utiliza las plantillas** para mantener una estructura consistente al crear documentación nueva.
4. **Incorpora nuevos contenidos** en la categoría más adecuada, evitando mezclar temáticas no relacionadas.
5. **Mantén la documentación actualizada** para que siga siendo útil a largo plazo.

Este repositorio está concebido como una base de conocimiento en evolución continua: su estructura puede ampliarse conforme crezcan los contenidos y las necesidades de documentación.
